# my-world

Source for [dillonfrolek.com](https://dillonfrolek.com) — a single static page, no build step.

- `index.html` — the page
- `main.css` — all styles (light + dark via `prefers-color-scheme`)
- `Images/` — portrait, logo, favicon
- `CNAME` — custom domain for GitHub Pages

To work on it locally, open `index.html` in a browser or run `python3 -m http.server`.
